# B 站完整美劇搜尋

輸入劇名，列出 B 站上**能直接從頭看到尾的完整版**，按播放量排序；點一下就跳到 B 站播放。
另有「最新上線」分頁，列出最近 30 天上傳的完整美劇。

剪輯、解說、學英語筆記、叫你去網盤下載的引流影片會被自動隱藏（可以展開查看）。

## 怎麼用

1. 在這台電腦上雙擊 `start.bat`。
   - 第一次執行時 Windows 防火牆會問要不要允許，請勾選「私人網路」並允許，否則 iPad 連不上。
2. 黑色視窗會顯示一個網址，例如 `http://192.168.1.23:8756`。
3. 在 iPad 的 Safari 輸入那個網址（iPad 要和電腦在同一個 Wi-Fi）。
   - 想要像 App 一樣：Safari 的分享按鈕 →「加入主畫面」。
4. 不用時關掉黑色視窗即可。

劇名可以打英文原名、台灣譯名或大陸譯名，工具會自動對應成 B 站上用的名字，並在結果上方顯示「同時搜尋：…」讓你確認有沒有對應錯。

## 串流片單（Netflix／HBO Max／Prime Video）

第三個分頁「串流片單」可以看這三個平台（美國區）**現在有的**劇和電影，以及**即將上線**的作品與日期。點任何一張海報，就會用它的中文名和原名直接去 B 站找完整版。

第一次使用要設定一組免費的 TMDB 金鑰（只需一次）：

1. 到 https://www.themoviedb.org 註冊並登入，在「設定 → API」申請 API 金鑰。
   申請表的 Application URL 填 `http://localhost` 即可，類型選個人。
2. 把專案資料夾裡的 `config.example.toml` 複製一份，改名為 `config.local.toml`，把金鑰貼進引號裡存檔。
   「API Key」或「API Read Access Token」都可以。這個檔案不會進 git。
3. 重新執行 `start.bat`。

沒設定金鑰也沒關係，「搜尋」和「最新上線」照常可用。

要知道的事：

- 可以用「全部類型」下拉選單按類型篩選（喜劇、劇情、犯罪、科幻…；劇和電影的類型清單不同）。
- TMDB 給「劇」的官方類型只有 16 種，沒有愛情、恐怖、驚悚（這些只有電影有）。所以劇的選單下方多了一組「更多（依關鍵字，較不精確）」：愛情、恐怖、驚悚、歷史古裝、情境喜劇、青春校園、超級英雄、醫療、律政、真實故事改編、迷你影集。這組是靠 TMDB 的關鍵字標記篩的，會有漏掉或混進不太相關的作品。
- 片名以**繁體中文（台灣譯名）**顯示；點下去搜 B 站時，工具會自動改用大陸譯名（例如畫面顯示「六人行」，實際搜「老友记」）。台灣沒有譯名的，顯示大陸譯名轉成的繁體字。
- 「現在有的」按熱門度排序，每次載入 20 部，可以一直「載入更多」，但不是完整目錄。
- **「即將上線」只包含各平台原創作品的首播／新一季日期**（未來 90 天）。「某部舊片下個月會加入 Netflix」這種上架預告，免費資料來源沒有。
- **即將上線的電影資料很少**（實測每個平台 0–4 部），劇的資料比較齊。
- 片單資料來自 TMDB 與 JustWatch。本工具使用 TMDB API，但未經 TMDB 認可或認證。

## 找電影

搜尋框不用選劇或電影，直接輸入名字，工具會自己判斷（靠豆瓣的資料：有集數的是劇，沒有的是電影）。判斷錯的時候，結果上方有一顆「其實是劇集／電影，重搜」的按鈕。

電影用另一套判斷：主要看時長是否接近片長，並排除解說、逐幀細讀、原聲音樂、遊戲實況等。

- 工具會向 TMDB 查片長（需要已設定金鑰），時長落在片長的 85%–115% 才算完整正片。
- 查不到片長時，只有標題寫了「正片／完整版／中字／藍光」之類字樣、而且長度像電影的，才算完整；其他放在「可能不完整」。
- **好萊塢電影在 B 站上的完整正片本來就少**（版權片常被下架），搜不到是常態；也可能搜到同名的別部作品（例如搜《蝙蝠俠：黑暗騎士》會出現樂高蝙蝠俠的影片），請看標題確認。

## B 站拒絕查詢時

B 站對沒登入的程式會拒絕一部分查詢。工具**不會也不應該繞過**這個防機器人機制，而是：

- 先查最容易成功的，被拒絕就停手，用已拿到的結果，並標示「這次的結果可能不齊全」。
- 列出被跳過的查詢，各附一個「在 B 站打開」的連結，你可以用自己的 B 站 App 或瀏覽器點開看。
- 在背景每隔幾分鐘慢慢補查一個（每個最多試 3 次），補到了畫面會自己更新。

## 結果怎麼看

| 標籤 | 意思 |
|---|---|
| 全 11 季／第 5 季／第 1–3 季 | 這個資源涵蓋的範圍 |
| 合併長片 · 22 段 | 每一段是好幾集合在一起的長片，要自己拖進度條找集數 |
| 一集一段 · 24 集 | 每一段就是一集 |
| 合集 · 7 支影片 | UP 主把多支影片串成的合集 |
| 可能不完整 | 拿不準的不會丟掉，收在下面並寫出原因 |
| 已隱藏 | 被判定為剪輯／解說／引流等，展開可以看到每一條的原因 |

## 要知道的限制

- **每次搜尋要等十幾秒到半分鐘。** B 站會擋查得太快的程式，所以工具刻意放慢。同一部劇 15 分鐘內再搜是立刻出來。
- **連續搜很多部劇會被 B 站暫時擋住**，畫面會顯示「B 站暫時限制查詢，請過幾分鐘再試」或「這次的結果可能不齊全」。等幾分鐘就好；工具不會也不應該去繞過這個限制。
- **資源隨時可能被下架。** 工具每次都是即時查，但今天能看的下週不一定還在。
- **要看 1080P 以上，通常得在 B 站自己那邊登入。** 這是 B 站的規則，和本工具無關；本工具不登入、不存任何帳號資料。
- **「是不是美劇」「完不完整」都是從標題、時長、分段推斷的**，不會百分之百準。
- 為了對應劇名，你輸入的**劇名**（只有劇名）會送到豆瓣，查不到時送到 Wikidata。
- 只能在家裡同一個 Wi-Fi 內使用，電腦要開著。

## 開發

```bash
uv sync                 # 安裝
uv run pytest           # 測試（不會連到真的 B 站）
uv run python run.py    # 啟動
uv run python -m tests.manual_stub   # 用假資料看畫面，http://localhost:8757
```

- `app/classifier.py`：判斷「完整版」的規則，純邏輯。遇到判斷錯的實例，先在 `tests/test_classifier.py` 加一個案例再改規則。
- `app/bilibili.py`：B 站查詢（匿名、放慢節奏、被擋就退讓）。
- `app/movie_classifier.py`：電影的判斷規則，同樣是純邏輯。
- `app/tmdb.py`、`app/config.py`：串流片單資料與本機設定。
- `app/backfill.py`：被 B 站拒絕的查詢，在背景慢慢補齊。
- `app/aliases.py`：劇名對應。
- `app/pipeline.py`：搜尋與「最新上線」的流程。
- `app/server.py`、`app/static/index.html`：網頁服務與畫面。
- 設計與計畫文件在 `docs/superpowers/`。
